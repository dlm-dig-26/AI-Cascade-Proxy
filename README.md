# AI-Cascade-Proxy

An assisted content-production pipeline for an irreverent short-form social brand.

The system ingests a source link, runs it through a **cascade** of processing
stages (acquire → analyze → ideate → script → produce → review → package), and
hands a human a ready-to-upload render pack for TikTok, Instagram Reels,
YouTube Shorts, and X. A human reviews every piece against a fair-use checklist
and performs the final upload — the pipeline does the production work, not the
posting.
